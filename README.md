EN:

Greetings!

About the Project
Create your own unique RPG world powered by an AI Game Master. The project is currently in the MVP stage and is fully functional and ready to play!

Prerequisites
AI Network API Key: Compatible with any LLM provider (configured via in-app settings).
Node.js 20+

Quick Start

Extract the downloaded archive into your preferred directory.
Open a terminal inside the `last-signal-local` folder.
Run the following commands:


pnpm install
pnpm dev

Once the setup completes, open http://localhost:5173/ in your browser to start playing!
If you run into any bugs or issues, feel free to reach out on Telegram: @co3dal
